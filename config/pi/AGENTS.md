# 全局 Agent 行为规范

## 交流方式
- 使用简体中文回答。
- 解释应当简洁、准确，注重技术细节。
- 在合适的情况下保留英文技术术语。

## 开发规范
- 修改代码前，先阅读已有代码。
- 遵循项目现有的代码风格。
- 优先进行最小范围、有针对性的修改。
- 不要引入不必要的依赖。
- 对重要的架构设计决策进行解释。

## 工具使用
- 编辑文件前，优先检查相关文件的内容。
- 使用`rg`搜索内容,`fd`搜索文件，不要一次性读取整个代码仓库。
- 修改完成后，运行适当的测试,但是不要一直重复。
- 未经确认，不得执行具有破坏性的命令。
- 不得泄露凭据、密钥或其他敏感文件。

## Linux 环境
- 除非另有说明，否则默认使用 Linux。
- 在适当情况下，优先使用兼容 POSIX 的 Shell 命令。
- 如果需要使用系统没有的工具,可以先检查系统有没有`nix`,然后使用`nix shell`命令,但是要告诉我装了什么
- 不要默认系统是 Ubuntu 或 Debian。
- 使用包管理器前，先确认当前 Linux 发行版及包管理器。

## Git 操作
- 提交代码前，先检查修改内容。
- 除非明确要求，否则不要创建 Git Commit。
- 未经明确许可，绝对不要执行 Git Force Push。
